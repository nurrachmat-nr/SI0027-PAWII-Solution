# Pertemuan 2 - UI/UX Design (Figma) & Ekosistem Deployment Modern (PaaS)

Solusi referensi untuk materi slide `Materi-Pertemuan-02-UIUX-Figma-Deployment-PaaS.pptx`.

## Tujuan

- Berlatih menyusun wireframe, mockup, dan prototype menggunakan Figma.
- Mempraktikkan alur deployment modern: menerbitkan halaman statis ke platform PaaS (Vercel/Netlify).

## Struktur

```
pertemuan-02-uiux-figma-deployment-paas/
├── figma-reference.md   # acuan hasil praktik Figma yang diharapkan
└── static-site/         # halaman statis lengkap & siap deploy
```

## Catatan Penting

Figma adalah alat desain berbasis web sehingga **tidak dapat disertakan sebagai berkas** dalam repositori ini. Bagian praktik Figma dipandu melalui `figma-reference.md` yang menjelaskan hasil yang diharapkan.

## Menjalankan secara lokal

```bash
cd static-site
npx http-server -p 5500
# buka http://localhost:5500
```

Starter kit latihan (`figma-checklist.md`, `DEPLOY.md`, dan `static-site/` belum lengkap) tersedia di repositori terpisah [SI0027-PAWII-Project](https://github.com/nurrachmat-nr/SI0027-PAWII-Project).
