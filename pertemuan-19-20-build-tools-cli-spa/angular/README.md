# Solusi Referensi - Angular Standalone

Lihat README utama pada folder [`pertemuan-19-20-build-tools-cli-spa`](../README.md) untuk penjelasan lengkap environment variable, cara menjalankan, dan kaitannya dengan Tugas Project Mandiri.

Jalankan cepat:

```bash
npm install
npm start              # development -> environment.development.ts
npm run build           # production  -> environment.ts
```
